# 6 Initial Project Plan

### Resources and dependencies

The initial resources are three student developers, their development computers, VS Code, Git, GitHub and a labelled sample dataset. Later implementation requires a database, application hosting and an AI service or locally executable model. Phase 2 will compare these options against hardware requirements, usage limits, cost and the semester schedule. No paid-service budget or production deployment is assumed.

Stakeholder validation depends on access to a custodian or approved proxy. Live-data use depends on authorization and suitable field definitions. AI evaluation depends on labelled requests and compatible asset examples. Financial and environmental reporting depends on documented input values and calculation factors.

| Risk | Effect on the project | Planned response |
| --- | --- | --- |
| Limited staff or data access | Operational assumptions cannot be validated directly | Use approved proxies and labelled sample records; distinguish their evidence from staff findings |
| Scope exceeds available effort | Required functions remain incomplete | Implement the core exchange first and review feature depth against course requirements |
| AI service cost or outage | Recommendations become unavailable | Assess service limits and cost before selection; preserve standard search and request processing |
| Poor AI recommendations | Users receive unsuitable candidates | Enforce hard constraints before ranking and evaluate against labelled requests |
| Missing cost or environmental inputs | Impact reports contain unsupported estimates | Require source values and units; omit estimates whose required inputs are unavailable |
| Conflicting edits or inconsistent requirements | Integration errors and unclear ownership | Use individual commits, task branches and peer review |
