# 6 Initial Project Plan

### Development method

The proposed method uses short iterations within the course phases. Each iteration will select a defined requirement, implement its behavior, execute its acceptance cases and obtain peer review before integration. Scope or rule changes will be recorded against the affected requirement ID. Feasibility decisions will precede technology selection, and the requirements specification will precede architecture and detailed design. [R1, pp. 7–10]

The first implementation increment will establish user permissions, asset records and the request-to-receipt workflow. Subsequent increments will add classification and matching, extend maintenance and life-cycle handling, and complete notifications, reporting and the remaining AI functions. This sequence defines implementation order without removing the medium-priority requirements from scope.
