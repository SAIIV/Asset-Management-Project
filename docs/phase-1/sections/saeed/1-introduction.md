# 1 Introduction

### Project purpose

The Intelligent, AI-Powered Circular Campus Resource Exchange and Asset Life Cycle Management System is a proposed internal web application through which university departments can publish surplus assets, request suitable items and document their transfer. It will also record inspections, repairs and final life-cycle actions against each asset. AI functions will suggest classifications, rank compatible resources and summarize recorded activity; authorized users will retain control of approvals and asset decisions. [R1, pp. 1–6]

This Phase 1 report defines the project scope, stakeholder responsibilities, requirements-gathering approach, initial requirements and development plan for COSC 336 Introduction to Software Engineering. The requirements are an initial proposal based on the course documents. Operational roles and acceptance thresholds are proposed for the prototype, not established university policy. Stakeholder interviews and prototype testing have not yet been conducted.
